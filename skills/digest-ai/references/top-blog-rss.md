## 使用策略

1. **AI Digest 扫描频率**：每天扫描一次，抓取最近 24 小时的更新
2. **内容筛选**：关注 AI/ML/LLM/AGI 相关的深度技术文章、产品发布、行业分析
3. **降级策略**：如果 RSS 解析失败，使用 Jina Reader 从博客 URL 获取最新文章
4. **交叉验证**：与 Hacker News、HuggingFace 等其他源交叉印证，提高准确性

## 技术实现

推荐使用 Python 的 `feedparser` 库解析 RSS：

```python
import feedparser

def fetch_rss_feed(url):
    feed = feedparser.parse(url)
    for entry in feed.entries:
        title = entry.get('title')
        link = entry.get('link')
        published = entry.get('published')
        summary = entry.get('summary', '')
        # 进一步处理...
```

或使用 Jina Reader 统一处理：

```python
import httpx

def fetch_with_jina(url):
    response = httpx.get(f"https://r.jina.ai/{url}", headers={"Accept": "text/markdown"})
    return response.text
```
