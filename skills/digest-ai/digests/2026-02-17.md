## 1.【新发现】Qwen3.5 发布：原生多模态 + 视觉 Agent 能力

阿里 2/16 发布 Qwen3.5，首次实现原生多模态（文本+图像+音频+视频统一架构），具备「视觉代理能力」可自主操作手机和桌面应用。开源版 397B 参数，比前代推理成本降低 60%、大负载效率提升 8 倍。闭源版 Qwen-3.5-Plus 支持 100 万 token 上下文。

**为什么值得关注：** 这是 Agent 能力竞赛的又一重磅入局者。Qwen3.5 直接对标 GPT-5.2、Claude Opus 4.5、Gemini 3 Pro，且成本优势明显。开源+原生多模态+Agent 能力三合一，对做 Agent 产品的团队来说是一个非常实用的底层选择。HN 408 分 / 191 评论，热度极高。

来源：[Qwen 博客](https://qwen.ai/blog?id=qwen3.5) | [HN 讨论](https://news.ycombinator.com/item?id=47032876) | [CNBC](https://www.cnbc.com/2026/02/17/china-alibaba-qwen-ai-agent-latest-model.html) | [GitHub](https://github.com/QwenLM/Qwen3.5)

## 2.【新发现】xAI 大重组：半数联合创始人出走，Macrohard 部门亮相

## 4.【新发现】智谱 GLM-5 开源：744B 参数，编码能力逼近 Opus 水平

2/12 智谱正式开源 GLM-5，参数规模从上代 355B 扩展至 744B（激活 40B）。SWE-bench-Verified 得分 77.8，TerminalBench 2.0 得分 56.2，编码体感接近 Claude Opus 4.5 水平。此前以 "Pony Alpha" 之名在 OpenRouter 匿名走红，身份揭晓后引发热议。

**为什么值得关注：** 国产开源模型在编码能力上首次接近国际顶尖水平。"匿名上线先跑分再揭牌"的营销策略说明对自身实力有信心。对想要自主部署代码 Agent 的国内企业来说，GLM-5 提供了新的可选项。

来源：[量子位](https://www.qbitai.com/2026/02/378654.html) | [CnDBA](https://www.cndba.cn/dave/article/131831)

## 5.【新发现】小红书开源 FireRed-Image-Edit：图像编辑 SOTA

2/14 小红书超级智能团队开源 FireRed-Image-Edit-1.0，基于 Diffusion Transformer 的通用图像编辑模型。在 GEdit 基准得分 7.92，超越 Qwen-Image-Edit 和 Seedream 4.0 等闭源模型。使用 1.6B 训练样本（经清洗保留 1 亿高质量），采用预训练+SFT+RLHF 三阶段训练。HuggingFace 今日最高 379 upvotes。

**为什么值得关注：** 小红书不声不响在 AI 基础模型上的投入成果出来了。开源 SOTA 图像编辑模型意味着高质量图像处理能力的门槛大幅降低，对内容创作工具链条影响深远。

来源：[arXiv](https://arxiv.org/abs/2602.13344) | [GitHub](https://github.com/FireRedTeam/FireRed-Image-Edit) | [HuggingFace](https://huggingface.co/FireRedTeam/FireRed-Image-Edit-1.0) | [Pandaily](https://pandaily.com/xiaohongshu-open-sources-fire-red-image-edit-achieves-sota-across-multiple-benchmarks)
