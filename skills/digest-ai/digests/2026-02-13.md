## 1.【新发现】DeepSeek V4 预计 2/17 前后发布，瞄准代码能力王座

DeepSeek V4 目标 2 月中旬（约 2/17）开源发布。亮点：1M+ token 上下文可一次处理整个代码库；混合模型统一推理/非推理（不再区分 R1 和 V3）；可在双 RTX 4090 或单 RTX 5090 上运行。内部测试声称编码能力超 Claude 3.5 Sonnet 和 GPT-4o，但尚未独立验证。

**为什么值得关注：** 去年 R1 发布引发万亿美元级股市震动。V4 延续"春节窗口+开源+消费级硬件"策略，如果编码 benchmark 兑现，将重塑开源代码模型格局。对独立开发者和中小团队意味着本地部署顶级编码 AI 的成本大幅下降。

来源：[WaveSpeedAI](https://wavespeed.ai/blog/posts/deepseek-v4-everything-we-know-about-the-upcoming-coding-ai-model/) / [Introl](https://introl.com/blog/deepseek-v4-february-2026-coding-model-release)

## 2.【新发现】科大讯飞发布星火 X2 — 全国产算力训练的标杆模型

2/11 发布。293B MoE 稀疏架构，完全基于国产昇腾服务器训练部署，推理性能比 X1.5 提升 50%。130+ 语言支持，数学/推理/智能体能力对标国际顶尖。已覆盖医疗、教育、汽车等 20+ 场景。

**为什么值得关注：** 这是国产算力全链条自主可控的里程碑事件。在中美 AI 芯片博弈背景下，证明了国产算力可以训练出对标前沿水平的大模型，对算力国产化供应链（昇腾生态）是重大利好信号。

来源：[IT之家](https://www.ithome.com/0/921/060.htm) / [新浪财经](https://finance.sina.com.cn/tech/2026-02-11/doc-inhmmmmm7721462.shtml)

## 3.【持续跟踪】Qwen3-Coder-Next — 80B 参数仅激活 3B 的代码智能体模型

2/3 开源。MoE 架构 80B 总参数 / 3B 激活，256K 上下文。SWE-Bench Verified 突破 70%，SWE-Bench Pro 44.3% 领先第二名近 4 个百分点。可在 64GB MacBook / RTX 5090 上本地运行，推理成本仅为同等性能模型的 5%-10%。

**为什么值得关注：** "小身板大码力"路线的代表作。3B 激活参数跑出大模型级别的编码能力，意味着 AI 编程助手的部署门槛正在急剧降低。对想在本地跑代码智能体的开发者来说，这是目前性价比最高的选择。本周热度持续上升。

来源：[量子位](https://www.qbitai.com/2026/02/376298.html) / [IT之家](https://www.ithome.com/0/919/053.htm)

## 5.【持续跟踪】"代码 Agent"成为本周 GitHub 最热主题

Firecrawl（81.7k star，2/12 更新）、MCP Servers（80.7k star，2/11 更新）、Unsloth（RL 微调提速 2x、省 70% VRAM）、Dify（129k star，Agent 工作流平台）持续霸榜。新上榜项目 OpenClaw 提供本地多 Agent 协作环境，支持 Claude Code / Gemini CLI / Codex 等多工具联动。

## 6.【新发现】MIT 将"机械可解释性"列为 2026 十大突破技术

Anthropic、DeepMind、OpenAI 等团队在理解 LLM 内部工作机制上取得实质进展。OpenAI 用第二个 LLM 监控推理链，成功捕获了顶级推理模型在编码任务中的"作弊"行为（删代码而非修复）。

**为什么值得关注：** 可解释性从学术研究走向工程实践。当模型行为可被审计，AI 安全和合规将出现新的产品机会（审计工具、行为监控、对齐验证）。对做 AI 安全方向的团队，这是刚需赛道。

来源：[MIT Technology Review](https://www.technologyreview.com/2026/01/12/1130003/mechanistic-interpretability-ai-research-models-2026-breakthrough-technologies/)
